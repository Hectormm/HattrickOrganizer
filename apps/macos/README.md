# Hattrick Organizer for macOS (React Native prototype)

This React Native for macOS prototype currently implements three screens:

- **Plantilla** opens an `.hrf` file with the native macOS file picker (or accepts pasted text) and reads the team name, first-team players, and player skills. It also imports team spirit, confidence, and coach modifier when the HRF contains them. It prefers HO's current `[lineup]` section and falls back to `[lastlineup]`, restoring the supported formation, player assignments, individual behaviours, team tactic, attitude, and any timed substitutions found in the selected section. The 5-3-2 formation supports three central midfielders as in the current HRF lineup.
- **Alineación** supports six formations, including the 5-5-0, player assignment to exact Hattrick role groups, direct player swaps between positions, position-valid individual player behaviours (normal, offensive, defensive, towards middle, and towards wing), and match tactic selection, including Creative Play and Long Shots. “Calcular mejor once” also optimizes those behaviours against the selected sector objective. With seven opponent ratings available, it compares all 42 formation and team-tactic combinations, optimizes a lineup for each, and lets the user apply the top recommendations. “Calcular mejor once” starts with a one-to-one player assignment and refines it against the sum of seven estimated team-sector ratings, or against opponent sector matchups when all seven opponent ratings are entered. The matchup heuristic weights midfield three times and the six attack/defence comparisons once; it is a lineup aid, not a match-outcome prediction. No player is selected twice and slots stay empty when the imported squad has fewer than eleven players. The screen displays the seven estimates for the current draft lineup, suggests beneficial bench changes, and lets the user save up to three timed substitution drafts and preview the sector ratings at a selected match minute.
- **Team Analyzer** compares the current lineup's seven ratings against a manually entered opponent profile or an imported opponent `.hrf`. When the HRF contains a supported current match lineup, it displays those assignments, tactic, and formation; changing the formation or tactic estimates an optimized alternative. It uses the spirit, confidence, coach modifier, and attitude from the HRF when available, plus the shared match weather and the venue opposite your team. Individual manual values can override the estimates in the matchup comparison. With a full own lineup and all seven opponent ratings, the legacy HO match engine can simulate 1,000–100,000 matches and show win/draw/loss percentages, average goals, and common scorelines. This is a local simulation of HO's ten-action match model, not an official Hattrick prediction. The rival profile, HRF lineup, and imported match context persist locally. Historical match download and opponent selection from the original Team Analyzer are not ported yet. It also calculates squad skill, form, stamina, experience, and loyalty averages, and ranks three player profiles for each role group.
- Match spirit, confidence, coach modifier, attitude, venue, and the imported roster, draft lineup, formation, team tactic, match weather, individual player behaviours, substitution drafts, and preview scenario are saved in macOS Application Support on macOS and in the browser's local storage on web. They are restored on the next launch in the same app or browser profile.

The estimates port the original `RatingPredictionModel` contribution factors for all five player behaviours, and include form, loyalty, experience, stamina, central-sector overcrowding penalties, and the known sector-rating multipliers for Attack in the Middle, Attack on Wings, Counter-attacks, Creative Play, and Long Shots. Team-sector estimates apply the editable team spirit, confidence, coach modifier, attitude, and venue; they default to HO's standard lineup values until the user enters match-specific data. Sector ratings still omit specialty-event effects and opponent-specific match odds. Player weather factors for Technical, Quick, and Powerful specialties are included, and Pressing ratings account for its extra stamina loss averaged across the 90-minute rating calculation. For non-normal tactics, the screen separately estimates HO's tactic level: Passing for Attack in the Middle/Attack on Wings, defensive-line skills and form for Counter-attacks, defending, form, experience, loyalty, stamina, and Powerful specialty for Pressing, passing, form, experience, and Unpredictable specialty for Creative Play, and scoring, set pieces, and loyalty for Long Shots. Pressing uses the selected weather. The optional match simulator ports HO's legacy ten-action engine and does not include the full Hattrick match engine or specialty events. Substitution drafts and HRF imports support minute, score-difference, and red-card criteria; the rating preview evaluates them against an editable scenario but does not simulate substitution events or match outcomes. Position/behaviour changes, full HRF match-order export, historical match data, and CHPP sync are not connected yet. Tactical choices and substitution plans are persisted as a local draft and do not write or send a Hattrick match order.

## Local setup

The app targets React Native 0.76.9 with `react-native-macos` 0.76.12 and reuses the shared screens with React Native Web for a browser build. Storage and HRF picking use platform adapters: macOS bridges, iOS/Android native modules, and browser storage/file input. iOS and Android JavaScript bundles resolve successfully, but their native host projects have not been scaffolded yet. It requires Node.js; the macOS target also requires Xcode and CocoaPods. From this directory:

```sh
npm install
npm run macos
```

For the browser version, run `npm run web` and open `http://127.0.0.1:5173/`. Create a static web build with `npm run build:web`; generated files go to `dist-web/`. HRF import uses the browser's file picker and stays on the device. Use Node 20.19 or newer for the toolchains. The macOS native project is in `macos/`.
